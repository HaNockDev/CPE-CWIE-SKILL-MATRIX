# ส่งออกข้อสอบ

“JSON พร้อมรูป” ฝังรูปทุกใบไว้ในไฟล์เดียว นำเข้ากลับได้ ไฟล์จะใหญ่ขึ้นตามจำนวนรูป ส่วน “JSON (ไม่มีรูป)” เก็บเฉพาะรหัสอ้างอิงรูป และ CSV ไม่รวมรูป
